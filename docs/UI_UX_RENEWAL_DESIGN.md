# UI/UXリニューアル設計ドキュメント

- 作成日: 2026-07-04
- 対象サイト: 大國造形 かんたん3Dプリントサービス
- 参照: `docs/SERVICE_DESIGN.md`
- 目的: サービス設計で定義された「初心者でも迷わず、安心して、手頃に3Dプリントを注文できる」価値を、UI/UXとマーケティング導線に落とし込む

---

## 1. リニューアルの結論

現行サイトは、3Dビューア、自動チェック、3素材プリセット、即時見積もりなど、MVPに必要な機能はかなり揃っている。一方で、画面の第一印象は「暗色のCAD/製造ツール」に寄っており、サービス設計書で定義されている「日本語で、迷わず、高品質な造形が届く」「白基調 + 清潔で初心者向け」というブランド体験とはまだ距離がある。

リニューアルでは、以下を最優先にする。

1. トップページを「説明ページ」ではなく「その場で見積もれる入口」にする。
2. 注文画面を「作業台UI」から「案内される注文カウンター」に変える。
3. 不安を抱えた初心者に対し、価格・納期・素材・品質保証を先回りして説明する。
4. DMM.makeやJLC3DP直接利用と戦う軸を明確にし、「安い」だけでなく「失敗しない」「面倒がない」を売る。
5. SEO・SNS・作例コンテンツにつながる情報設計を用意し、初回注文後のリピート導線まで見据える。

目指す体験は「3Dプリントに詳しい人向けの見積もりツール」ではなく、「3Dデータを持っている初心者が、ファイルを置くだけで安心して注文できるサービス」である。

---

## 2. サービス上の前提

### 2.1 勝つべき軸

`SERVICE_DESIGN.md` の定義に従い、本サービスは以下で選ばれる。

- 登録なしで見積もりまで到達できる
- 素材選択が3プリセットで迷わない
- 日本語で不安を解消できる
- 表示金額が総額・税込・追加費用なし
- 全品検品と造形保証がある
- DMM.makeより手頃で、JLC3DP直接利用より簡単

反対に、以下では勝負しない。

- 最安値
- 即納
- 素材数の多さ
- 上級者向けの細かな工法指定

### 2.2 ターゲット

MVPで最優先するのは以下の2層。

| ペルソナ | 主な不安 | UI/UXで解くこと |
| --- | --- | --- |
| 趣味モデラー | 価格、印刷可否、素材選択 | アップロード即見積もり、データチェック、用途別素材 |
| フィギュア/創作系 | 表面品質、細部再現、著作権 | 高精細レジン作例、品質保証、権利ガイド |

小規模事業者は将来のアップセル対象とし、MVPでは法人色を前面に出しすぎない。

## 3. 現状UI/UX診断

### 3.1 良い点

- トップページに、3ステップ、素材、料金例、納期、FAQ導線がある。
- `/order` にアップロード、3Dプレビュー、解析、素材選択、見積もり、住所入力までの流れがある。
- 素材が `スタンダード樹脂 / 高精細レジン / タフナイロン` の3つに整理されている。
- 料金が `造形価格 + 基本手数料 + 送料` で明朗に表現されている。
- FAQや料金ページなど、信頼を補う静的ページが存在する。

### 3.2 課題

| 領域 | 現状 | 課題 |
| --- | --- | --- |
| ブランド印象 | 黒背景、CADグリッド、銅色アクセント、3D演出 | かっこよいが、初心者には専門的・高そう・難しそうに見える |
| ヒーロー | 大きなコピー + 3Dシーン + CTA | 「アップロードするだけ」という価値が体験として始まらない |
| トップ導線 | セクションを読ませてから `/order` に遷移 | 見積もり前の心理的ハードルが残る |
| 注文画面 | フルスクリーンのビューア + 右パネル | CADツール的で、購入フローとしての安心感が弱い |
| 素材選択 | 詳細情報はあるが、用途に対する誘導が弱い | 「自分の用途ならどれか」が即決しづらい |
| 信頼証拠 | 全品検品や保証はテキスト中心 | 写真、検品基準、価格比較、作例が不足 |
| 納期説明 | 10〜16日は明示 | 遅い理由と安心材料がCTA近くに不足 |
| マーケ導線 | 料金/FAQはある | SEO用の素材ガイド、作例、初心者ガイド、比較記事への拡張余地が大きい |

### 3.3 改善の方向

現行の「技術的にできる」印象を残しつつ、第一印象を「頼みやすい」「見積もりだけでも試せる」「ちゃんと届きそう」に寄せる。

暗色の没入感は3Dビューアや注文中の作業エリアに限定し、トップページと静的ページは明るく清潔なサービスサイトへ寄せる。これにより、初心者の不安を下げながら、ビューアの技術感も必要な場所で活かせる。

## 4. リニューアルコンセプト

### 4.1 コンセプト

**「白い注文カウンター。ファイルを置くと、価格と届く日がわかる。」**

3Dプリント工場の無骨さではなく、受付カウンターのような安心感をつくる。ユーザーは専門的な設定画面を操作するのではなく、必要なことを順番に確認していく感覚で注文できる。

### 4.2 体験原則

1. 最初にファイルを置ける
   - トップページのファーストビューにアップロードゾーンを置く。
   - 「無料で見積もり」ではなく「ファイルを置いて総額を見る」を主CTAにする。

2. 価格・納期・保証を隠さない
   - お届け10〜16日を早い段階で明示する。
   - 「急ぎではなく、手頃に失敗なく作りたい人向け」と正直に言う。

3. 素材は用途で選ばせる
   - 「SLA」「MJF/SLS」より先に「試作品」「フィギュア」「動く部品」を見せる。
   - 詳細スペックは折りたたみや詳細ビューに置く。

4. 不安が出る場所に答えを置く
   - アップロード直後: 印刷できるか
   - 素材選択時: どれを選べばよいか
   - 見積もり時: 追加費用がないか
   - 決済前: いつ届くか、品質不良時どうなるか

5. 実物の証拠を増やす
   - CGや抽象画像だけでなく、造形物写真、検品風景、梱包、表面品質の接写を使う。

## 5. ビジュアル方針

### 5.1 トーン

現在の「黒いCAD空間」から、以下へ移行する。

- 清潔
- 手頃
- 日本語で親切
- 少しだけ精密
- 趣味にも実用品にも使える

「先端的」「高級」「職人っぽい」を強く出しすぎない。初心者にとっては、かっこよさよりも「見積もりだけ試して大丈夫そう」が重要。

### 5.2 カラーパレット案

| 用途 | 色 | 意図 |
| --- | --- | --- |
| 背景 | `#F7F6F2` | 白すぎない清潔なベース |
| 面 | `#FFFFFF` | 入力・カード・注文内容 |
| 主テキスト | `#1E2528` | 読みやすい濃いグラファイト |
| 補助テキスト | `#66706D` | 柔らかい説明文 |
| 境界線 | `#E3DFD7` | 紙と樹脂のような薄い線 |
| CTA/アクセント | `#C86B3A` | 現行の銅色を弱めて継承 |
| 成功 | `#2F7D5C` | 印刷可・検品OK |
| 警告 | `#B7791F` | 注意点 |
| エラー | `#C2413A` | 注文不可・要修正 |
| ビューア背景 | `#101416` | 3Dモデルが映える暗色 |

アクセント色は基本的にCTAと選択状態に限定する。成功・警告・エラーは状態色として必要な範囲だけ使う。

### 5.3 タイポグラフィ

- 本文: 読みやすい日本語サンセリフを基本にする。
- 見出し: 現行の `Noto Serif JP` はブランド感があるため、ロゴや大見出しに限定して使う。
- 数値: 価格、サイズ、日付は桁が揃うように `font-variant-numeric: tabular-nums` を使う。
- 見出しは大きくしすぎず、初心者向けの説明文が読みやすい余白を優先する。

### 5.4 写真・アセット

追加したい写真。

- 手のひらに載る造形物
- フィギュア表面の接写
- 実用品パーツの利用シーン
- 検品中の写真
- 梱包済みの発送前写真
- 3素材の質感比較

トップのヒーローに抽象的な3D画像だけを置くのではなく、アップロードUIと作例写真を組み合わせる。ユーザーが確認したいのは「どんなものが、いくらで、どの品質で届くか」である。

| パス | 目的 | マーケティング上の役割 |

- 作例

## 7. トップページ設計

### 7.1 ファーストビュー

目的: 3秒で「ここにファイルを置けば価格がわかる」と理解させる。

構成:

- 左: 価値訴求コピー
- 右または中央: 大きなアップロードゾーン
- 下: 3つの安心材料

コピー案:

- H1: `3Dデータをアップロードするだけ。総額がその場でわかります。`
- リード: `素材選び、海外発注、検品、国内発送までまとめて代行。1個から、会員登録なしで見積もれます。`
- 主CTA: `ファイルを置いて総額を見る`
- 補助CTA: `料金例を見る`

安心材料:

- 登録なしで見積もり
- 追加費用なし・税込総額
- 全品検品・造形保証
- お届け目安10〜16日

### 7.2 価格例セクション

目的: 「自分のものはいくらくらいか」を想像させる。

現在の料金例は良いが、写真と比較軸を追加する。

表示項目:

- 作例写真
- サイズ
- 素材
- 総額
- 向いている用途
- DMM.makeより手頃であることを示す補足

注意:

- 断定的な比較表現は景表法リスクがあるため、「条件により異なります」「同等条件での目安」と併記する。
- 「最安」ではなく「手頃」「見積もりが明朗」を主語にする。

### 7.3 素材セクション

目的: 選択肢が少ない安心を伝える。

3カードで表示する。

| 素材 | 見出し | 補足 |
| --- | --- | --- |
| スタンダード樹脂 | 迷ったらこれ | 試作品、小物、実用品 |
| 高精細レジン | 細かい表現に | フィギュア、ミニチュア、原型 |
| タフナイロン | 強度が必要な部品に | 動く部品、治具、屋外寄り |

各カードには「用途」「表面」「強度」「価格感」を短く表示し、専門用語は二段目に置く。

### 7.4 不安解消セクション

目的: 注文前の離脱理由を潰す。

配置順:

1. データが印刷できるか不安
2. 素材が選べるか不安
3. 価格が増えないか不安
4. 品質が悪かったら不安
5. 届くまで長くて不安

各不安に対して、1画面で答える。

例:

- `アップロード直後に、サイズ・体積・薄すぎる壁をチェックします。`
- `品質不良は無償で再製造または返金します。`
- `送料・手数料込みの税込総額を先に表示します。`

### 7.5 納期セクション

目的: 弱点を誠実さに変える。

表現:

- `お届けまで10〜16日。急ぎではない注文に向いています。`
- `国内即納ではありません。そのかわり、価格を抑え、検品してから発送します。`

6段階の進捗を横長または縦型タイムラインで表示する。

ステップ:

1. 注文確定
2. データチェック完了
3. 製造中
4. 製造完了・輸送中
5. 検品完了・発送
6. お届け完了

### 7.6 最終CTA

目的: 読了後に見積もりへ戻す。

文言:

- `見積もりだけでも大丈夫です`
- `会員登録なしで、総額を確認できます`
- CTA: `ファイルをアップロードする`

## 8. 注文フロー設計

### 8.1 基本方針

現行の `/order` は「ビューア中心の制作ツール」に見える。リニューアルでは、以下のステップ式にする。

1. アップロード
2. 印刷チェック
3. 素材・数量
4. 見積もり確認
5. お届け先・支払い

デスクトップでは3Dビューアを左、案内パネルを右に置く構成を維持してよい。ただし右パネルは「設定リスト」ではなく「いま何を決めるか」が明確なウィザードにする。

### 8.2 ステップ1: アップロード

表示すべき内容:

- 対応形式: STL / OBJ / STEP / GLTF / GLB
- ファイルサイズ上限
- 見積もりまでは無料
- 会員登録不要
- サンプルファイルで試せる導線

改善案:

- トップページのアップロードゾーンと見た目を揃える。
- ドロップ後に `/order` へ遷移する場合も、読み込み中に「ファイルを解析しています」を表示する。
- ファイル形式エラーは日本語で具体的に出す。

### 8.3 ステップ2: 印刷チェック

状態:

| 状態 | 表示 |
| --- | --- |
| 解析中 | スケルトン + `サイズと体積を確認しています` |
| 問題なし | 緑のチェック + `このモデルは印刷に適しています` |
| 注意あり | 黄色 + `印刷は可能ですが、薄い箇所があります` |
| 注文不可 | 赤 + `このサイズは選択中の素材では造形できません` |

テキストは、専門用語ではなく行動につながる表現にする。

例:

- 悪い: `non-manifold edge detected`
- 良い: `閉じていない面があります。穴をふさぐと印刷しやすくなります。`

### 8.4 ステップ3: 素材・数量

現行の素材カードを、用途起点に変更する。

カード見出し:

- `迷ったらこれ`
- `細かい表現に`
- `強度が必要な部品に`

詳細を見る前に、以下を1行で比較できるようにする。

- 価格感
- 表面のなめらかさ
- 強度
- 向いているもの
- おすすめ度

補助導線:

- `素材選びに迷う` を押すと、2〜3問の診断を表示する。
- 質問例: `使い道は？` `細かい模様がありますか？` `力がかかりますか？`

### 8.5 ステップ4: 見積もり確認

ここが最重要CVポイント。

表示すべき情報:

- 合計税込
- 造形価格
- 基本手数料
- 送料
- 送料無料までの残額
- お届け予定日
- 追加費用なし
- 品質保証

CTA周辺の不安解消:

- `この金額から追加費用はかかりません`
- `製造前にスタッフがデータを確認します`
- `造形品質の不良は無償で再製造または返金します`

### 8.6 ステップ5: お届け先・支払い

住所フォームは現在の構成を活かしつつ、以下を追加する。

- 郵便番号から住所補完
- 必須項目の明確化
- エラーを項目直下に表示
- 支払い前に利用規約・権利確認チェック
- 注文後の進捗通知の説明

権利確認の文言例:

`このデータが第三者の権利を侵害しないこと、または造形の許可を得ていることを確認しました。`

### 8.7 モバイル

モバイルでは、3Dビューアと設定パネルの横並びをやめる。

構成:

1. 上部にステップバー
2. 3Dプレビューは折りたたみ可能
3. 見積もり合計は下部固定
4. CTAは常に画面下部

価格とCTAがスクロールの奥に埋もれるとCVRが落ちるため、モバイルでは合計金額の下部固定を優先する。

## 9. コンポーネント設計

### 9.1 UploadDropzone

役割:

- トップと注文画面で共通利用する。

必須要素:

- ドラッグ状態
- ファイル選択ボタン
- 対応形式
- 無料見積もり/会員登録不要
- エラー状態
- サンプルファイル導線

### 9.2 QuoteSummary

役割:

- 価格不安を取り除く。

必須要素:

- 税込合計
- 内訳
- 送料無料表示
- お届け予定
- 追加費用なしの注記
- CTA

### 9.3 MaterialPresetCard

役割:

- 用途で素材を選ばせる。

必須要素:

- 用途見出し
- 素材名
- 作例画像
- 価格感
- 向いているもの
- 苦手なもの
- 選択状態

### 9.4 PrintabilityStatus

役割:

- 「このデータで大丈夫か」をすぐ返す。

必須要素:

- 解析中
- OK
- 注意
- ブロック
- 問題箇所ハイライトの切り替え
- 日本語の改善案

### 9.5 TrustStrip

役割:

- CTA近くで信頼を補強する。

表示:

- 1個からOK
- 登録なし見積もり
- 全品検品
- 追加費用なし
- 品質保証

### 9.6 ProgressTimeline

役割:

- 納期の長さを透明化する。

表示:

- 6段階ステータス
- 現在地
- 次のアクション
- メール通知の有無

## 10. マーケティング観点の設計

### 10.1 ファネル

| フェーズ | ユーザー心理 | 主な接点 | UI/UXの役割 |
| --- | --- | --- | --- |
| 認知 | 3Dプリントを頼みたいが方法がわからない | SEO/SNS/作例 | 初心者向けであることを明示 |

### 10.2 メッセージング

主メッセージ:

`3Dデータをアップロードするだけ。総額がその場でわかります。`

補助メッセージ:

- `素材選びで迷わない、3つのプリセット。`
- `手数料・送料込みの税込総額を先に表示。`
- `全品検品してから国内発送。`
- `お届けまで10〜16日。急ぎではない注文に向いています。`
- `海外発注や関税の手続きは不要です。`

避ける表現:

- `最安`
- `爆速`
- `誰でも完璧`
- `業界最高品質`
- 根拠のない `DMMより必ず安い`

### 10.3 競合比較の扱い

DMM.make:

- 認める強み: 国内生産、即納、素材数、信頼
- 本サービスの強み: 料金のわかりやすさ、選びやすさ、登録なし見積もり、初心者向け

JLC3DP直接:

- 認める強み: 価格
- 本サービスの強み: 日本語、検品、国内発送、関税/英語/住所入力の代行

比較ページでは、競合を否定せず「向いている人が違う」と整理する。これは信頼形成に効く。

## 11. コピー設計

### 11.1 基本文体

- です・ます
- 専門用語は使う前に説明する
- 不安に対して先回りする
- 誇張しない
- 短く、具体的に言う

### 11.2 UI文言例

| 場所 | 文言 |
| --- | --- |
| アップロード前 | `3Dファイルをここに置くと、総額を計算します` |
| 解析中 | `サイズと体積を確認しています` |
| チェックOK | `このモデルは印刷に適しています` |
| 注意 | `印刷は可能ですが、薄い箇所があります` |
| ブロック | `この素材では最大サイズを超えています` |
| 素材選択 | `使い道に近いものを選んでください` |
| 見積もり | `この金額から追加費用はかかりません` |
| 納期 | `お届け目安: 10〜16日` |
| CTA | `この内容で注文へ進む` |
| 完了 | `ご注文を受け付けました。次はデータチェックです。` |

### 11.3 CTAの使い分け

| 文脈 | 推奨CTA |

## 14. 受け入れ基準

### 14.1 UX

- 初見ユーザーがトップのファーストビューで「ファイルを置くと見積もれる」と理解できる。
- 会員登録なしで見積もりまで進めることが明確に伝わる。
- 価格、納期、保証が注文前に確認できる。
- 素材3種の違いが用途ベースで理解できる。
- 注文不可/注意/OKの状態が専門用語なしで理解できる。
- モバイルでも合計金額とCTAが迷子にならない。

### 14.2 マーケティング

- 「DMM.makeより簡単で手頃」「JLC3DP直接より安心」というポジションが伝わる。
- 価格例と作例があり、ユーザーが自分の注文を想像できる。
- 納期の遅さを隠さず、進捗通知と検品で納得感を作れている。
- SEOページへ拡張できる情報構造になっている。

### 14.3 アクセシビリティ

- キーボード操作でアップロードボタン、素材選択、数量変更、CTAに移動できる。
- フォーカス状態が視認できる。
- 画像に意味のあるaltが入っている。
- 色だけで状態を伝えない。
- フォームエラーは項目直下に表示される。

## 15. 実装時の注意

- 現行の3Dビューア、解析、見積もりロジックは活かす。
- フレームワークやスタイリング基盤は変更しない。
- まずはCSS変数とレイアウト変更で印象を変える。
- 実物写真が不足する間は、抽象CGではなく「作例として理解できる画像」を優先する。
- 競合比較は誠実に書き、勝てない軸を無理に強調しない。
- 「高品質」表現には、検品基準や保証を近くに添える。
- 納期は必ず10〜16日として明示し、即納を期待させない。

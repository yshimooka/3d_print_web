## 1. サービス概要

### 1.1 コンセプト

> **「3Dデータをアップロードするだけ。日本語で、迷わず、高品質な造形が届く。」**

ユーザーが3Dデータ(STL/STEP/OBJ/3MF)をアップロードし、素材を選び、住所を入力するだけで、検品済みの高品質な立体造形物が自宅に届くワンストップサービス。

### 1.2 事業の実態(社外秘)

- 受注後、実際の造形は [JLC3DP](https://jlc3dp.com/jp) に発注する(製造委託)。
- 弊社は **受注UI・日本語サポート・検品・国内再発送** を担う。
- つまり本サービスの提供価値は「造形そのもの」ではなく、
  **①初心者でも失敗しない注文体験 ②日本語の安心感 ③検品による品質保証 ④面倒の代行(海外発注・関税・英語)** である。
- 料金はJLC3DPより高くなるため、**「JLC3DPを直接使える人」はターゲットにしない**。この層を追うと価格勝負になり必ず負ける。

### 1.3 ポジショニング

| | 価格 | 使いやすさ(初心者) | 納期 | 品質保証 |
|---|---|---|---|---|
| JLC3DP直接利用 | ◎ 激安($0.3〜) | △ 英語混じり・専門用語多い・関税/住所入力が不安 | △ 中国から1〜2週間 | △ 自己責任 |
| DMM.make | △ 高い(小物でも数千円になりがち) | ○ 日本語だが素材70種で迷う・見積もりが分かりにくい | ○ 即納あり(+100%) | ◎ 国内・手厚い |
| **本サービス** | **○ DMMより明確に安い** | **◎ 初心者特化・選択肢を絞る・即時見積もり** | △ 10〜16日(正直に明示) | **◎ 全品検品・造形保証** |

**一言ポジション: 「DMM.makeの半額以下で、DMM.makeより簡単。急がない個人のための3Dプリントサービス」**

戦うべき軸は「**簡単さ × 安心 × 手頃な価格**」。戦ってはいけない軸は「納期」(即納はDMMに勝てない)と「最安値」(JLC3DP直接に勝てない)。納期は弱点なので、**隠さず正直に表示して期待値を管理する**(後述)。

## 3. 市場・競合分析

### 3.1 競合: DMM.make

- 国内最大手。素材約70種、[即納サービス](https://make.dmm.com/print/option/express/)(通常価格+100%)、データ制作代行など多機能。
- 強み: 国内生産・納期・素材数・信頼・[手厚いサポート](https://make.dmm.com/blog/news/dmmmake-3dpservice/)。
- **初心者にとっての弱み(=本サービスの攻めどころ)**:
  1. **価格**: 趣味用途では「見積もりが高額」という声が多い([利用者ブログ](https://kitto-yakudatsu.com/archives/3253))。
  2. **選択肢過多**: 素材70種は初心者には選べない。
  3. **見積もりの分かりにくさ**: 容積ベースの価格計算はアップロードするまで見当がつかない。
  4. **会員登録が先**: 見積もり前にDMMアカウント登録が必要で離脱要因になる。

### 3.2 供給元: JLC3DP

- [部品$0.30〜](https://jlc3dp.com/)の圧倒的低価格。SLA(レジン)/MJF・SLS(ナイロン)/SLM(金属)/FDM等を提供([方式まとめ](https://green-keys.info/en/types-of-3d-prints-that-can-be-ordered-from-jlc3dp-and-their-expansion-rates/))。
- SLAはサンディング仕上げで表面が滑らか([素材比較レビュー](https://burariweb.info/electronic-work/jlc3dp-material-sample.html))。品質は趣味用途に十分という[国内レビュー](https://qiita.com/Gavady/items/e1ddfb108ed2c037fd67)多数。
- リードタイム: 製造2〜5日+国際配送で、日本着まで概ね1〜2週間。
- 注意点: 形状によっては[特別料金](https://jlc3dp.com/jp/help/article/3d-printing-special-charges-case)(大型・薄肉・中空等)が発生する。**自動見積もりロジックに必ず織り込むこと。**

### 3.3 その他の代替手段

- 3Dプリンタ購入(Bambu Lab等、3万円台〜): 「置き場所・手間・失敗」を嫌う層が本サービスの顧客。訴求では「買わずに試せる」を強調。
- ものづくりカフェ/ファブ施設: 都市部限定・時間拘束。全国配送で優位。

## 4. ビジネスモデル

### 4.1 収益構造

```
売上 = 造形価格(原価×マークアップ) + 基本手数料 + 国内送料
原価 = JLC3DP造形費 + JLC3DP→弊社の国際送料(按分) + 検品人件費 + 梱包資材 + 決済手数料(3.6%)
```

### 4.2 価格設計

- **造形価格 = JLC3DP見積もり × 2.5(目安)**。それでもDMM.makeの1/2〜1/3に収まるケースが多い(例: JLC3DPで$3の小物 → 弊社約1,200円 → DMMでは4,000円前後)。
- **基本手数料: 500円/注文**(検品・国内梱包費。小口注文の赤字防止)。
- **国内送料: 全国一律500円、5,000円以上で無料**(初心者に分かりやすい一律制)。
- **最低注文金額は設けない**(手数料で担保)。「1個からOK」は初心者への強い訴求。
- 表示は**総額・税込・追加費用なし**を徹底。「アップロード即・確定金額」がDMMへの最大の差別化。

### 4.3 想定ユニットエコノミクス(小物1個の例)

| 項目 | 金額 |
|---|---|
| ユーザー支払額(造形1,200 + 手数料500 + 送料500) | 2,200円 |
| JLC3DP造形費+国際送料按分 | ▲700円 |
| 検品・梱包(10分×人件費按分+資材) | ▲350円 |
| 決済手数料 | ▲80円 |
| **粗利** | **約1,070円(粗利率 ~49%)** |

粗利率40%以上を維持ラインとし、下回る素材/サイズ帯は価格係数を調整する。

### 4.4 リピートとLTV

- 3Dプリントは「1回成功すると習慣化する」性質が強い。**初回体験の成功率**が最重要KPI。
- リピート施策: 注文履歴からの再注文(1クリック)、過去モデルの保存、2回目以降の手数料割引クーポン。

## 5. サービスフロー(オペレーション)

### 5.1 注文〜配送

```
[ユーザー] アップロード → 自動チェック → 素材/数量選択 → 即時見積もり → 決済(カード)
    ↓
[弊社] 受注確認 → データ最終チェック(半自動) → JLC3DPへ発注(1営業日以内)
    ↓
[JLC3DP] 製造(2〜5日) → 国際配送(5〜8日) → 弊社着
    ↓
[弊社] 検品(寸法・表面・破損) → 合格: 国内梱包 → 発送(ヤマト/ゆうパケット)
                              → 不合格: JLC3DPへ再発注 or 返金(ユーザーへ即連絡)
    ↓
[ユーザー] 受け取り(注文から10〜16日)
```

### 5.2 ステータス通知(体験の要)

納期が長い分、**進捗の見える化で不安を消す**。メール+マイページで6段階を通知:

1. 注文確定 → 2. データチェック完了 → 3. 製造中 → 4. 製造完了・輸送中 → 5. 検品完了・発送(追跡番号) → 6. お届け完了(+レビュー依頼)

※「JLC3DP」「中国」の名は出さず「提携工場で製造中」と表現する。

### 5.3 検品基準(初版)

- 寸法: 公称±0.5%または±0.5mmを超える歪みはNG
- 表面: サポート跡の顕著な残り、層割れ、欠けはNG
- 造形失敗・破損: 無条件で再発注(ユーザー負担なし)
- 検品記録(写真1枚以上)を注文IDに紐付けて保存 → 「全品検品」の証拠かつ紛争時のエビデンス

### 5.4 造形保証ポリシー

- **造形品質起因の不良は無償再製造または全額返金**(業界標準に合わせつつ「全品検品済み」を前面に)。
- データ起因の問題(薄すぎる壁など)は事前の自動チェックで警告した場合は対象外。ただし初回注文に限り1回まで救済(初心者の失敗を許容するブランド作り)。

## 6. UX設計

### 6.1 設計原則

1. **登録なしで見積もりまで到達できる**(DMMとの最大の差)。決済時に初めてメール登録。
2. **選択肢は最初3つまで**。素材はまず「スタンダード/高精細/タフ」の3プリセット。詳細素材は「もっと見る」の奥に。
3. **専門用語を使わない**。「SLA光造形」ではなく「高精細レジン(フィギュア向き)」。
4. **不安を先回りで潰す**。アップロード直後に「このデータは印刷できます ✓」を明示。
5. **納期は正直に、進捗は細かく**。「お急ぎの方はDMM.makeをおすすめします」と書けるくらいの誠実さがブランドになる。

### 6.2 コア注文フロー(3ステップ)

```
Step 1: アップロード
  ├ ドラッグ&ドロップ(STL/OBJ/STEP/3MF、複数可)
  ├ 3Dビューアで即プレビュー(既存のthree.js資産を活用)
  ├ 自動チェック: サイズ上限/最小肉厚/破れメッシュ → 問題は日本語で平易に表示
  │   例:「壁が薄すぎる箇所があります(0.4mm)。1mm以上にすると安心です」
  └ 見積もり額をこの時点でリアルタイム表示(素材はスタンダード仮選択)

Step 2: 素材と数量
  ├ 3プリセットをカード表示(写真・向いている用途・価格・精度を比較)
  │   「スタンダード樹脂」… 試作・実用品に / 最安
  │   「高精細レジン」… フィギュア・ミニチュアに / 表面なめらか
  │   「タフナイロン」… 動く部品・強度が必要なものに
  ├ 選択のたびに価格が更新
  └ 迷う人向け「30秒でわかる素材診断」(2〜3問の分岐)

Step 3: 確認と決済
  ├ 総額(造形+手数料+送料、税込)とお届け予定日(「7/18〜7/22」形式)
  ├ 住所入力 → カード決済(Stripe想定)
  └ 完了画面でマイページ/進捗通知の案内
```

### 6.3 サイトマップ

```
/                    トップ(価値訴求 + アップロードCTA)
/order               注文フロー(Step1〜3、1画面ウィザード)
/materials           素材ガイド(写真多め・比較表)
/pricing             料金の仕組み(計算例つき)
/gallery             作例ギャラリー(用途別)
/guide               初心者ガイド(データの作り方・入手先・よくある失敗)
/faq                 FAQ(納期・品質・著作権・返品)
/mypage              注文履歴・進捗・再注文
/legal/*             特商法表記・利用規約・プライバシーポリシー
```

### 6.4 トップページ構成

1. **ヒーロー**: 「3Dデータを、アップロードするだけ。」+ その場でドロップできるアップロードゾーン(トップ自体がStep 1の入口)
2. 3ステップ図解(アップロード → 素材を選ぶ → 届く)
3. 料金例(「このサイズのフィギュアが◯◯円」を実物写真つきで3例)
4. 選ばれる理由(全品検品 / 総額即表示 / 1個からOK / 日本語サポート)
5. 作例ギャラリー抜粋
6. 納期の正直な説明(10〜16日 + 進捗通知の画面例)
7. FAQ抜粋 + CTA

### 6.5 UIトーン

- 白基調 + 1アクセントカラー。製造業的な無骨さではなく「無印良品的な清潔さ」。
- 写真は実際の造形物を多用(CGレンダリングだけにしない — 品質不安の払拭が目的のため)。
- 文体は「です・ます」、専門用語には必ず説明を添える。

## 7. マーケティング戦略

### 7.1 基本方針

初心者は「3Dプリント 依頼」よりも **課題ワード**で検索する。獲得はコンテンツSEOを主軸に、指名検索をブランドで刈り取る。

### 7.2 チャネル別施策

**コンテンツSEO(主軸・低コスト)**
- 「3Dプリンター 買わない 選択肢」「フィギュア 立体化 依頼」「Fusion360 作ったもの 出力」「DMM.make 料金 高い」等の比較・課題キーワードで記事化。
- 「DMM.makeとの比較」記事は正直に書く(即納・素材数はDMM優位と認めた上で、価格と簡単さで選ばれる構成)。信頼が武器になる。

**SNS(X / YouTube)**
- 検品風景・造形物の開封動画は3Dプリント界隈で拡散しやすい。
- ユーザー作例のリポスト(投稿許諾を注文完了メールで依頼)。

**コミュニティ**
- Fusion 360 / Blender / VRoidの日本語コミュニティ、Boothクリエイター周辺への浸透。
- 「初回500円クーポン」の紹介プログラム。

**リスティング(補助)**
- 「3Dプリント 代行」「3D出力 サービス」等の顕在ワードのみ少額。CPAが粗利1,070円×想定リピートを超えない範囲。

### 7.3 ローンチ施策

- 先行50名に「素材サンプルセット同梱」(JLC3DPで安価に量産できるため原価は軽い)。
- 作例コンテスト(ハッシュタグ投稿)で初期ギャラリーとUGCを同時に確保。

## 8. リーガル・リスク

| リスク | 対応 |
|---|---|
| JLC3DP依存(値上げ・品質変動・停止) | 第2委託先(Elecrow/PCBWay等)の口座を予め開設。価格係数を変数化しておく |
| 納期遅延(国際輸送) | 表示納期に+3日のバッファ。遅延時は自動通知+次回クーポン |
| 著作権・意匠権(版権フィギュア等) | 利用規約で禁止明記+注文時チェックボックス。目視で明白な侵害物は発注前に停止 |
| 銃器・危険物形状 | 発注前の目視チェックフローに組み込む(全件データを人が一度見る運用) |
| 関税・輸入 | 弊社が輸入者となるため個人ユーザーには関税事務が発生しない(これ自体が訴求点) |
| 特商法・景表法 | 特商法表記、「高品質」表現の根拠として検品基準を公開 |
| 個人情報 | 住所・決済情報の取り扱いをプライバシーポリシーに明記。決済情報はStripeに委譲し非保持 |

## 9. KPI

| フェーズ | 北極星指標 | 補助KPI |
|---|---|---|
| ローンチ〜3ヶ月 | 初回注文完了数 | アップロード→見積もり到達率、見積もり→決済CVR(目標8%)、不良再発注率(<5%) |
| 3〜12ヶ月 | 月間注文数と粗利額 | リピート率(90日以内、目標25%)、CPA、NPS |

計測設計: アップロード開始/見積もり表示/素材選択/決済開始/完了をイベント計測し、ファネルのどこで初心者が脱落するかを最優先で観察する。

## 10. 開発ロードマップ

### Phase 1 — MVP(〜2ヶ月)
- トップ + 注文フロー(アップロード/3Dビューア/自動見積もり/3素材/Stripe決済)
- 見積もりエンジン: JLC3DP価格体系の再現(体積・バウンディングボックス・方式別係数 + 特別料金条件)
- 受注管理は管理画面最小限(一覧・ステータス手動更新) + JLC3DPへの発注は手動
- ステータス通知メール、特商法・規約ページ

### Phase 2 — 体験強化(3〜5ヶ月)
- マイページ(履歴・再注文)、素材診断、素材追加(カラーレジン・金属)
- 自動メッシュ修復、肉厚チェックの精度向上
- 素材ガイド/ギャラリー/ブログ(SEO開始)

### Phase 3 — スケール(6ヶ月〜)
- JLC3DP API連携による発注自動化(可能なら)
- 法人向け(請求書払い・見積書PDF)、複数パーツ一括注文
- 第2委託先の組み込み、レビュー機能
